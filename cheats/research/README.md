# NES cheat memory-test research — not a gameplay verification

This is a candidate research file, not the active cheat catalog. The exact-ROM
probe observed memory enforcement and reset for 57 codes across 22 collection
entries (including duplicate ROMs). It did **not** verify the named gameplay
effects, full playthroughs, stage behavior, or safety. Codes are not enabled
by this research file and must not be presented as gameplay-verified.

Evidence: https://github.com/midoali250/akg-retro-games-linux/actions/runs/42011446252

Candidate descriptions and codes originate from the pinned libretro-database
revision identified in the JSON, with a source URL per candidate. The database
