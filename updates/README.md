# Independent update channel — windows

This private directory reserves the update channel for this platform only. It is not a working updater or a production feed. Releases and previews remain independent and are not overwritten by this configuration. The application must obtain and verify a signed manifest with a pinned publisher public key, compare product/platform and version, verify size and SHA-256 before installation, and ask the user for consent. Android must use OS installation confirmation. Never put a GitHub access token or signing private key in the app, repository files or manifests.

The safe primitives currently live in `bitvault-engine` on `engine/clean-foundation`, under `updates/client/python` for desktop; Android needs its own integration and verification. No public download origin, production public key, actual manifest, release signing configuration, or in-app integration is provided by this template. A private GitHub release is not anonymously downloadable without an authorized service or user access. Do not point this file at a production endpoint or mark it configured until the service, signing process and installation path have been tested.
